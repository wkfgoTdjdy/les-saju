# 🌈 LES SAJU

레즈비언 전용 사주. 생년월일로 사주 4주를 계산해 "사주에 새겨진 나의 레즈 기질"을 풀어준다.
futsal-saju의 자매 프로젝트 — 만세력·오행·페어 궁합 코어를 이식했다.

- **남성운 정산** — 전통 사주의 '남성운'(관성)을 커리어·카리스마로 재해석. 공석이면 축하 🎉
- **팸-부치 스펙트럼** — 십신(비겁·식상·재성·관성·인성) 분포로 티부~립스틱팸 좌표 산출, 반전 디테일 포함
- **일간 유형** — 10가지 레즈 유형 밈 (조용한 장작불형, 직진 소방차형, …)
- **신살 재해석** — 도화살(여자한테 인기 많은 살), 역마살(퀴퍼 원정살), 화개살, 홍염살
- **애인 찾을 스팟** — 오행별 추천 (클라이밍장 국룰, 레즈클럽 새벽 1시, 퀴어 북토크 …)
- **유홀(U-Haul) 지수** — 동거 속도 기질 수치화

## 원칙

- 셀프디스가 아니라 셀프축하. 이성애 전제 워딩("남편") 금지 — "남성"으로 표기.
- **프라이버시 최우선**: 로그인 없음, DB 없음. 생일은 결과 URL 쿼리로만 흐르고 서버에 저장되지 않는다. 결과 페이지는 noindex.
- 계산(만세력·십신·신살)은 코드에서 결정적으로. LLM 해석은 아직 없음 (아래 다음 단계).

## 실행

```bash
npm install
npm run dev
```

환경변수 없이 바로 동작한다. 양력/음력/음력(윤달) 지원, 태어난 시간은 선택 입력.

## 구조

```
src/
  lib/saju.ts        # 만세력 코어: 4주, 오행, 페어 궁합 (futsal-saju 이식)
  lib/les.ts         # LES 해석: 십신, 스펙트럼, 남성운 정산, 신살, 스팟, 유홀 지수
  components/        # BirthForm(입력), CopyLinkButton(공유)
  app/
    page.tsx         # 랜딩 + 생일 입력
    result/page.tsx  # 결과 리포트 (쿼리 파라미터 기반, 무상태)
```
