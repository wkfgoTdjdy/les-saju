# 🌈 LES SAJU

레즈비언 전용 사주. 생년월일로 사주 4주를 계산해 "사주에 새겨진 나의 레즈 기질"을 풀어준다.
futsal-saju의 자매 프로젝트 — 만세력·오행·페어 궁합 코어를 이식했다.

- **남성운 정산** — 전통 사주의 '남성운'(관성)을 커리어·카리스마로 재해석. 공석이면 축하 🎉
- **팸-부치 스펙트럼** — 십신(비겁·식상·재성·관성·인성) 분포로 티부~온팸 좌표 산출, 반전 디테일 포함
- **일간 유형** — 10가지 레즈 유형 밈 (조용한 장작불형, 직진 소방차형, …)
- **신살 재해석** — 도화살(여자한테 인기 많은 살), 역마살(퀴퍼 원정살), 화개살, 홍염살
- **애인 찾을 스팟** — 오행별 추천 (클라이밍장 국룰, 레즈클럽 새벽 1시, 퀴어 북토크 …)
- **동거지수** — 동거 속도 기질 수치화
- **커플 궁합** — 초대 링크를 애인에게 보내면 생일 입력 순간 **Gemini AI**가 궁합 리포트 생성.
  케미 점수, 싸움 매뉴얼, 먼저 연락하는 쪽, 동거지수, 금전운·성공운, 여행 케미, 고양이 입양 예상.
  **초대 1건당 딱 1회**만 완성 가능 (completed_at 원자적 갱신으로 보장).

## 원칙

- 셀프디스가 아니라 셀프축하. 이성애 전제 워딩("남편") 금지 — "남성"으로 표기.
- **프라이버시 최우선**: 로그인 없음. 저장하는 건 커플 궁합의 생년월일·닉네임뿐.
  솔로 사주는 완전 무상태(URL 쿼리로만). 결과 페이지는 전부 noindex, 코드가 곧 접근 토큰.
- 계산(만세력·십신·신살·궁합 점수)은 코드에서 결정적으로, AI에는 해석 문장만 맡긴다.

## 실행

```bash
npm install
npm run dev
```

환경변수 없이도 바로 동작한다 (Node 20+, `.nvmrc` 참고):

- **Supabase 미설정** → 인메모리 저장소 (서버 재시작 시 커플 데이터 소멸, 개발용)
- **GEMINI_API_KEY 미설정** → AI 해석 없이 계산된 궁합만 보여주는 미리보기 모드

## 프로덕션 설정

1. [Supabase](https://supabase.com) 프로젝트 생성 → SQL Editor에서 `supabase/schema.sql` 실행
2. `.env.local.example`을 `.env.local`로 복사하고 값 채우기
3. 배포는 Vercel 권장

## 구조

```
src/
  lib/saju.ts        # 만세력 코어: 4주, 오행, 페어 궁합 (futsal-saju 이식)
  lib/les.ts         # LES 해석: 십신, 스펙트럼, 남성운 정산, 신살, 연애 스타일, 연애운, 이상형, 스팟, 동거지수
  lib/couple.ts      # 커플 해석: 싸움 패턴, 연락, 동거, 금전·성공운, 여행, 고양이
  lib/llm.ts         # Gemini 호출 + 프롬프트 (계산은 코드, 해석만 LLM)
  lib/db.ts          # Supabase / 인메모리 저장소 (커플만 저장, 1회 제한)
  app/
    page.tsx                    # 랜딩 + 솔로 생일 입력
    result/page.tsx             # 솔로 결과 (쿼리 파라미터 기반, 무상태)
    couple/                     # 커플 시작 (초대 만들기 / 직접 입력)
    couple/join/[code]/         # 초대받은 쪽 입력 (1회 제한 안내)
    couple/result/[code]/       # 커플 결과 (계산 코너 + AI 심층 리포트)
    api/couples/...             # 커플 생성 / 완성 API
supabase/schema.sql  # DB 스키마
```
